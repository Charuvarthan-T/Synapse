# Use it with GitHub Copilot Chat

Once your graph is built, GitHub Copilot Chat's agent mode can call Graphify
automatically — it decides on its own when looking up codebase context would
help, using **your existing Copilot subscription**. You don't need to do
anything extra: just ask Copilot Chat a question about your codebase and it
may reach for Graphify instead of reading whole files.

Graphify never sees your Copilot account or any API key — it only ever runs
locally and returns text back to Copilot when asked.
