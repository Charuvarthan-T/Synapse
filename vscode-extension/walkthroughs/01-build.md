# Build your first graph

Open a Python project (or use the one you already have open). Synapse builds
a knowledge graph of your code **entirely on your machine** — no API key, no
network calls.

Run **Synapse: Rebuild Graph** from the Command Palette (`Ctrl+Shift+P`), or
just click the status bar item in the bottom-right corner.

Watch the status bar: it will show `provisioning...` the first time (setting
up a small private Python environment), then `building graph...`, then
`Synapse: N nodes` when it's done.
