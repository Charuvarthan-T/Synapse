# Ask questions about your code

Run **Synapse: Query Codebase** and ask something in plain language, e.g.
*"how does authentication work"* — Synapse searches the graph and shows you
the relevant functions, classes, and how they connect.

Or place your cursor on any function/class name and run
**Synapse: Explain Symbol at Cursor** for a focused look at just that one
symbol and its direct neighbors.
